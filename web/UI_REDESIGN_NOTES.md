# drive-unix 全頁面 UI/UX 重設

## 這一版改的是資訊架構與操作流程，不只是換色

- 新增永久左側導覽，將工作流程拆成「總覽、檔案瀏覽、同步工作區」與「儲存節點、傳輸任務、自動排程、系統設定」七個明確目的地。
- 首頁改為工作台總覽：呈現真實可取得的節點數、排程數、目前同步狀態與快取命中率，並提供常用操作與節點快捷入口。不虛構容量用量或歷史任務。
- 儲存節點由彈窗改成獨立管理頁，支援進入檔案、連線診斷、刪除及新增節點。
- 傳輸任務由覆蓋畫面的抽屜改成完整監控頁，呈現活動任務、進度、即時事件與停止操作。因原後端目前只暴露一個活動任務，此頁會明確說明沒有提供歷史任務清單。
- Cron 排程改成雙欄工作頁：左側清單與控制操作，右側建立表單和常見 Cron 範例。
- 系統設定改成獨立頁，使用內部設定導覽切換快取、介面偏好、安全限制與擴充 JSON。
- 檔案瀏覽器及雙欄同步工作區保留原有 Vue 操作和 API 流程，但放進新導覽架構；新增節點、檔案預覽及同步預檢仍以對話框呈現，符合短流程互動。
- 新增手機側邊導覽、窄螢幕兩欄轉換、表單焦點狀態、清楚的空狀態和 reduced-motion 支援。

## 後端與 API 相容性

未修改 `routers/`、`app.py`、快取邏輯或 API 路徑。現有 Vue 方法與 API 呼叫保留；`navigateTo()` 只是新的頁面路由函式，根據目的地載入相應資料。

## 驗證界線

已進行 HTML 結構與 JavaScript 語法檢查、Python 編譯檢查及基本模板平衡檢查。沒有真實遠端儲存節點的憑證或執行環境可用，因此未宣稱完成端到端同步、上傳或排程驗證。
